# CppME Chapter 21

This repository contains the source code and Visual Studio project files for Chapter 21 of the C++ Programming Made Easy series. The examples focus on core object-oriented and polymorphism concepts in C++, including virtual functions, overriding, abstract classes, and destructor behavior.

## Repository overview

The project is organized as a small solution containing one main project and several standalone example projects, each demonstrating a different C++ topic from the chapter.

## Project structure

- `CppME_Chapter21.cpp` – default starter file generated by Visual Studio.
- `CppME_Chapter21.vcxproj` and `CppME_Chapter21.vcxproj.filters` – main project configuration.
- `CppME_Chapter21.slnx` – solution file that references the chapter examples and the main project.
- `CppME_Chapter21_Example21.12/` – operator overloading example.
- `CppME_Chapter21_Example21.18/` – basic polymorphism example using virtual functions.
- `CppME_Chapter21_Example21.20/` – virtual destructor example.
- `CppME_Chapter21_Example21.22/` – abstract class and pure virtual function example.
- `CppME_Chapter21_Example21.29/` – polymorphism with overridden virtual methods.
- `CppME_Chapter21_Example21.30/` – additional polymorphism and override demonstration.

## Chapter topics covered

### Example 21.12: Operator overloading

This example defines a `Number` class with an overloaded `+` operator and demonstrates how custom objects can be added using user-defined operators.

### Example 21.18: Virtual functions and runtime dispatch

A base class `Shape` declares a virtual `draw()` function. Derived classes override it and show polymorphic behavior through a base-class pointer.

### Example 21.20: Virtual destructors

This example shows why a base class destructor should be virtual when deleting derived objects through a base pointer.

### Example 21.22: Abstract classes

A pure virtual function is used to create an abstract base class, preventing direct instantiation while allowing polymorphic derived classes to implement the required behavior.

### Example 21.29: Overriding behavior

Two derived classes override a virtual method and are invoked via a base-class pointer, demonstrating dynamic dispatch.

### Example 21.30: Additional override practice

A second example reinforces the same idea with different shapes, emphasizing the use of `override` and virtual dispatch.

## Build and run

This repository uses Microsoft Visual Studio C++ project files (`.vcxproj`), so the easiest way to build and run the examples is:

1. Open the solution file `CppME_Chapter21.slnx` in Visual Studio.
2. Select the desired project or example project as the startup project.
3. Build the solution using `Build > Build Solution`.
4. Run the project with `Debug > Start Without Debugging` or `F5`.
